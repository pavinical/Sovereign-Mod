# Changelog

## 1.2.6

- Registered naturally generated village buildings in the Build tab so existing artisan buildings, libraries, temples, and meeting places can be tracked by the clerk.
- Added relocation support for registered natural village structures while preserving their original vanilla structure template.
- Fixed duplicate entries appearing in the left-side sale menu.
- Improved relocation cleanup so moving built structures restores the old footprint instead of leaving a hole behind.
- Continued clerk GUI polish with tab/icon alignment and menu element positioning fixes.

## 1.2.5

- Expanded village trading with broader villager trade pools, artisan archetypes, and loop prevention for exploitable item conversions.
- Added authorized job block permits, civilian job block placement support, relocation tools, and village placement protections.
- Added biome-themed village name randomization and level-up celebration polish with sounds and scaled firework shows.
- Added artisan commissions for armorers, clerics, librarians, toolsmiths, and weaponsmiths, including repair, reforge, enchantment, potion, armor trim, ordering, pickup, abandon, and admin completion flows.
- Added emerald balance commands and the clerk ledger.
- Added village building plots, house and castle construction, upgrades, relocation, build timers, plot marking tools, and building XP gates for higher village tiers.
- Reworked the clerk table GUI with baked tab textures, icon tabs, adjusted alignment, live timers, and restored element textures.
